An operating system for single-board computers that boots the same way every time.

AtomixOS turns a small board into an appliance you can update from anywhere. Every image is built from one Nix flake, the root filesystem is read-only, and a bad update rolls itself back.

Flash your first board Read the docs

Two copies of the system, one place for your data

The eMMC holds two boot and root slots. The device runs from one while an update is written to the other, so a power cut mid-update never leaves it without a working system. Your configuration and logs live on /data, which no update touches.

How an update lands

  1. Write the spare slot

    A signed RAUC bundle is verified, then written to the slot that is not running.

  2. Boot into it

    U-Boot switches to the new slot and counts the attempt.

  3. Prove it is healthy

    Services, the network, and your containers must stay healthy for 60 seconds before the slot is committed.

  4. Or fall back

    After three boots that never prove healthy, U-Boot returns to the slot that worked.

What you get

Reproducible images
The same flake and inputs always build the same image, and each image carries its build policy.
A read-only root
The system is a squashfs image. Runtime changes vanish on reboot, so every boot starts clean.
Containers without rebuilds
Describe applications as Podman Quadlets in one config.toml; the base image never changes.
No default credentials
Each device is provisioned on first boot. SSH is key-only and closed on the WAN side unless you open it.
An isolated gateway
The LAN side gets DHCP, DNS, and NTP. Nothing is ever forwarded between LAN and WAN.
Optional fleet management
Enroll devices with Nixstasis to provision and reach them remotely, or leave it out entirely.

Get started

  1. Install the pinned tools.

    mise install --locked

  2. Build the image for your board.

    mise run build

  3. Flash it to the board's eMMC.

    mise run flash /dev/disk4

  4. Power on and provision the device from its first-boot console.

Provisioning covers the first-boot console, USB seeds, and Nixstasis enrollment.
